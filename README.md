
🎂 Пример дня рождения
Учебный проект для изучения веб-разработки на Django

📝 Описание
Приложение для управления днями рождения контактов. Установить источник, просматривать, редактировать и удалять записи о днях рождения. Создан как учебный проект для изучения основ работы с фреймворком Django.

Установка
1️⃣ Клонируйте репозитории
баш
git clone https://github.com/m2dyt/birthday_exsample.git
cd birthday_exsample
2️⃣ создать виртуальное окружение
баш
python -m venv venv
3️⃣ Активируйте окружение
Окна:

баш
venv\Scripts\activate
macOS/Linux:

баш
source venv/bin/activate
4️⃣ Выбирайте в зависимости
баш
pip install -r requirements.txt
5️⃣ Примените замену
баш
python manage.py migrate
6️⃣ Запустите сервер
баш
python manage.py runserver
🌐 Откройте браузер: http://127.0.0.1:8000/

✨ Функциональность
#	Функция	Описание
1	➕ Добавление	Добавление новых дней рождения контактов
2	👁️ Просмотр	Просмотр полного дня дней рождения
3	✏️ Редактирование	Изменение информации о контактах
4	🗑️ Удаление	Удаление записей о днях рождения
5	🔍 Фильтрация	Сортировка и фильтрация по различным критериям
💡 Как использовать
Добавление дня рождения
Открыть приложение в браузере

Нажмите на кнопку «Добавить»

Заполните форму:

Имя контакта

Дата рождения

Контактная информация

Сохраните запись

Просмотр дней рождения
На главной странице отображается список всех сохраненных дней рождения с полной информацией о каждом контакте.

Управление записями
Для каждой записи доступны кнопки:

Редактировать - изменить информацию

Удалить - удалить запись

⚙️ Полезные команды
баш
# Создать администратора
python manage.py createsuperuser

# Открыть админ-панель

# Запустить тесты
python manage.py test

# Создать миграцию
python manage.py makemigrations

# Применить миграции
python manage.py migrate

# Открыть интерактивную оболочку
python manage.py shell
