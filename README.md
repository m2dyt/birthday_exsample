# Birthday Example

Учебный проект на Django для управления днями рождения с системой поздравлений и пользователями.

## Функционал

### Управление днями рождения
- Добавление записей о днях рождения с указанием имени, фамилии и даты
- Загрузка фотографий для каждой записи
- Редактирование и удаление записей (доступно только автору)
- Присвоение тегов к записям о днях рождения
- Автоматический расчет времени до следующего дня рождения
- Проверка уникальности записей (комбинация имени, фамилии и даты)
- Валидация возраста (проверка реальности даты рождения)

### Система поздравлений
- Добавление текстовых поздравлений к записям о днях рождения
- Отображение всех поздравлений с указанием автора и времени создания
- Хронологическая сортировка поздравлений

### Система пользователей
- Регистрация новых пользователей
- Авторизация и выход из системы
- Расширенный профиль пользователя с полем биографии
- Привязка записей о днях рождения к авторам
- Защита операций редактирования и удаления (доступны только автору записи)

### Списки и навигация
- Просмотр всех записей о днях рождения
- Пагинация списка (10 записей на страницу)
- Детальный просмотр каждой записи с поздравлениями
- Оптимизированные запросы к базе данных (prefetch_related, select_related)

### Дополнительные возможности
- Защита от публикации записей с именами участников The Beatles (отправка уведомления администратору)
- Обработка необязательных полей (фамилия, теги, фото)
- Автоматическая обрезка лишних пробелов в именах

## Технологии

- Python
- Django
- SQLite (база данных)
- HTML-шаблоны
